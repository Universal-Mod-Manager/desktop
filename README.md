# UMM Desktop

## Prerequisites

- Node.js (LTS recommended)
- Rust (latest stable)
- pnpm

## Setup

Install dependencies:

```bash
pnpm install
```

## Development

Run the frontend in development mode:

```bash
pnpm dev
```

Run the full desktop application in development mode:

```bash
pnpm tauri dev
```

## Build

Build for production:

```bash
pnpm tauri build
```
